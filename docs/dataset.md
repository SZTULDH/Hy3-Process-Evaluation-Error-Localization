# 评测题集说明

## 规模与分层

| 难度 | 题数 | 依据 |
|------|------|------|
| easy | 5 | 单循环/内置操作可解，边界简单 |
| medium | 5 | 需哈希/双指针/排序等常规技巧 |
| hard | 4 | 期望较优复杂度，暴力可过小样例但过程不达标 |
| adversarial | 3 | 专为伪正确设计：公开测试过、对抗暴露缺陷 |

合计 **17** 题。

## 来源与构造

- 题型改编自常见算法面试/LeetCode 风格，**非直接照抄原题编号**，用例与伪正确解为自构。
- **正确对照样本**（easy 为主）：`mock_solution` 逻辑成立，公开+对抗均过，用于测误报率。
- **伪正确样本**：公开用例刻意避开缺陷触发条件；`adversarial_tests` 专打边界/归一化/缺失值等漏洞。
- 每题含 `ground_truth`：`first_error_step`、`error_types`、`truly_correct` 等，供评估器有效性验证。

## 自动校验

- 公开测试 → 结果正确性
- 对抗测试 → 真实正确性
- 过程评估 → 规则 + Critic + Checker 取证
